## 专业域

### 结构仿真与优化

主线工作。从几何清理、网格划分、边界条件到求解与后处理，关注的是「优化前后到底差多少」——质量、应力、模态、位移，要有可对比的数据，而不是一句「效果明显」。常用 Abaqus 做拓扑优化，也会用 CalculiX、ANSYS、COMSOL 交叉验证。

### 三维建模与 CAD 自动化

用 SolidWorks 建模，偏好参数化与脚本驱动：能写成脚本的就不手动点。交付格式常要 Parasolid (.x_t)，因为要直接喂给 Abaqus。装配体、工程图、批量导出都在射程内。

### 机械检测与工装

螺纹与螺纹孔的通规/止规检测。现实痛点是大批量小件全检占用大量人力，所以方向是半自动化的辅助工装与检测设备选型论证。

### AI 工具链

不是重度开发者，但会把 AI 助手连同插件、MCP、Skill 一整套搭起来，让它们真的能操作 SolidWorks、Abaqus、浏览器和文件系统。装插件、改配置、排查环境问题都自己动手，遇到坑会一直追到通为止。

## 跟我协作的 6 条规则

1. 先给结论和产物，再解释过程；不要反过来。
2. 动手前确认落盘路径，默认放 D 盘，产物给绝对路径。
3. 能用命令/脚本解决的，不要让他手点；能一次做完的，不要分三次问。
4. 专业术语第一次出现时用一句人话解释。
5. 交付时附证据：截图、结果文件、关键数值对比。
6. 做不到或不确定，直接说，并给出可行的替代方案。
